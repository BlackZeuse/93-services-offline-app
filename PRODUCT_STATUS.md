# 93 Services Offline App — Production Build Package

Designed & Developed by TECHART (PTY) LTD.

This package contains the production Android source, release signing material, company logo, PDF generator and an automated CI build workflow.

The final APK binary is produced by the included `build_release.sh` script on a machine with Android SDK/Gradle installed, or by the included GitHub Actions workflow after the repository is connected.

The app itself does not request internet access and does not require registration or a cloud account for normal operation.
